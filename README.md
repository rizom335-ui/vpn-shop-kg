# VPN Shop KG — Neon Mobile

Мобильный демонстрационный магазин с тёмным неоновым интерфейсом, фильтрами, поиском, избранным, корзиной, карточками товаров и WhatsApp-заказом. Фотографии загружаются по внешним URL с Unsplash и требуют интернета; замените их на лицензированные изображения конкретных товаров перед коммерческим запуском. Цены, характеристики и оценки — демонстрационные.

## Render

Загрузите содержимое **этой папки** в корень репозитория GitHub. В Render создайте Web Service: Runtime Node, Build Command `npm install`, Start Command `npm start`, Instance Free. Environment: `GEOBLOCK_ENABLED=true`, `MOBILE_ONLY=true`.

Проверка страны выполняется по серверному IP-запросу к ipwho.is. Это ограничение по стране IP, а не надёжное определение VPN. Проверяйте работу в продакшене; заголовки прокси и доверенная инфраструктура требуют дополнительной проверки перед запуском реального магазина. User-Agent фильтр Android можно обойти и он не является защитой. Сервис геолокации может быть недоступен, в этом случае доступ временно закрывается. В режиме разработки выставьте `GEOBLOCK_ENABLED=false` и `MOBILE_ONLY=false`.

## Local

`npm install && npm start` затем http://localhost:3000
